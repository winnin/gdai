# Project Roadmap

This roadmap outlines the planned features and improvements for G-DAI. The timeline and priorities may change based on community feedback and project needs.

## Q3 2024

- [ ] Add user authentication and authorization
- [ ] Improve semantic search ranking algorithms
- [ ] Add support for more document formats (e.g., DOCX, HTML)
- [ ] Enhance API documentation with more examples

## Q4 2024

- [ ] Implement real-time notifications for document processing
- [ ] Add admin dashboard for monitoring and analytics
- [ ] Internationalization (i18n) support

## Future Ideas

- [ ] Integration with cloud storage providers (AWS S3, GCP, Azure)
- [ ] Pluggable embedding models
- [ ] Community plugin system

---

_This roadmap is subject to change. Contributions and suggestions are welcome!_
